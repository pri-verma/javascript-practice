                                            JavaScript Execution Context

_____________________
|                   |
|                   |       -------->  Global Execution Context (GEC)  <= this
|     JavaScipt     |
|       Code        |       -------->  Function Execution Context (FEC)
|                   |
|                   |       -------->  Eval Execution Context (EEC) {Property of (GEC)}
|___________________|

# Global Execution Context will always present even if it has no value
# Global Execution Context of Browser and  Node.js is different
# In Browser, value of "this" will be window object 
# JavaScipt is single threaded




// JavaScipt will run in two phases :
_____________________
|                   |
|                   |       -------->  Memory Creation Phase (MCP) / Creation Phase
|     JavaScipt     |                  (Memory allocation, variable declaration)
|       Code        |      
|                   |       -------->  Execution Phase
|                   |                  (Execution of operators, function)
|___________________|

|   }                              |                        result1 -> undefined
|   let result1 = add(val1,val2)   |                        result2 -> undefined
|   let result1 = add(4,8)         |                (3) EXECUTION PHASE

                                                                                                 |

****************************************************************    CALL STACK   ****************************************************************
       
       _____________________________________
       |____________________________________|                                           _______________CODE_________________        
       |____________________________________|                                        1. |   one(){                         |
       |____________________________________|                                        2. |         two()                    |
       |____________________________________|                                        3. |   }                              |

       |______________three()_______________|                                        6. |         three()                  |
       |______________three()_______________|                                        7. |   }                              |
       |______________two()_________________|              ^                         8. |                                  |
       |______________three()_______________|              |                         9. |   three(){}                      |
       |______________two()_________________|              |                        10. |__________________________________|
       |______________one()_________________|              |                        
       |______GLOBAL_EXECUTION_CONTEXT______|            STACK                      
                                                         (LIFO)
                                                    Last In First Out


`````````````````````` Steps of Execution `````````````````````

# Line 1 will execute one()          ---|
# Line 2 will call two()                |
# Line 5 will execute two()             |------> one() 
# Line 6 will call three()              |
# Line 9 will execute three()        ---|

~ Line 9 three() result will go to Line 6 three()
~ Line 6 three() result will go to Line 5 two()
~ Line 5 two() result will go to Line 2 two()
~ Line 2 two() result will go to Line 1 one()

^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

# Line 2 will call two()             ---|
# Line 5 will execute two()             |------> two()
# Line 6 will call three()              |
# Line 9 will execute three()        ---|

~ Line 9 three() result will go to Line 6 three()
~ Line 6 three() result will go to Line 5 two()
~ Line 5 two() result will go to Line 2 two()

^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

# Line 9 will execute three()            ------> three()
